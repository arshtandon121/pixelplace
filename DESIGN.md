# PixelPlace — Neo Kinpaku

Creative north star: a dark urushi lacquer object inlaid with kinpaku gold. The live pixel canvas is the artifact. Chrome is quiet; gold is used where the product actually is (the grid, the CTA, live state).

## Mode
Landing is Persuade. The first viewport is Experience: the canvas leads.

## Color
- Lacquer black `oklch(7% 0.006 95)` page ground
- Raised lacquer `oklch(11% 0.006 95)` panels
- Kinpaku gold `oklch(84% 0.19 80.46)` CTA, wordmark, active rules
- Champagne `oklch(91% 0 0)` headlines
- Body `oklch(88% 0 0)`
- Muted `oklch(72% 0 0)`
- Verdigris `oklch(70% 0.12 188)` live / improved state only
- Hairline `oklch(78% 0 0 / 0.16)` default rules
- Strong gold hairline `oklch(74% 0.09 82 / 0.6)` on the canvas frame and focus

Never pure black. No purple-to-blue glows. No gray-on-gold.

## Type
- Display: Alumni Sans, weight 100–300, clamp 3.4–5.6rem
- Body: Albert Sans, 1rem / 1.7
- Measurement: JetBrains Mono, 11px, tracking 0.18em
- No Inter. No italic serif hero. No gradient text.

## Shape
Radii 2–8px. Hairlines, not thick gold borders. Almost no decorative shadow. Gold leaf sheen only on the primary button.

## Refuse
Eyebrow labels above headings. Nested cards. Icon tiles as page structure. Fake investor metrics. Bounce easing.
